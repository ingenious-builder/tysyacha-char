# Живые звуки «Тысячи чар»: что скачано (26.11, ветка feat/audio2)

Скачаны все 6 одобренных Артёмом наборов (26.11, «попробуй ещё раз скачать, да»), сверх списка ничего не брали. Лицензию каждого набора проверили сами на его странице. У Kenney она есть ещё и в License.txt внутри архива. Ничего не пропущено.

Куда сложено: каждый набор лежит в своей папке `D:/games/_snd_dl/<набор>/`. Архивы распакованы в `x/` той же папки через bsdtar (Windows tar.exe). Из архивов ничего не запускали, внутри только .ogg, .wav, License.txt и .url. Свои скрипты лежат отдельно: `_check/audio2/tools/` и `D:/games/_snd_dl_tools/`. Python запускался с `-I`.

Как скачивали:
- **Kenney.** Сначала открывали страницу набора. Потом обращались к `kenney.nl/download-link/<id>`: это тот же запрос, что делает кнопка «Continue without donating», он возвращает подписанную ссылку. Архив брали с kenney.nl.
- **opengameart.** Файлы из блока «File(s)» на странице набора. curl с браузерным User-Agent и Referer страницы, все ответы — 200, ни одного 403.

## Как сделано и проверено

- **Сборка** — `tools/build.py`, рецепт на каждый ключ. Каждый вариант проходит так:
  - обрезка тишины, мягкие края;
  - громкость K (макс. RMS окна 400 мс, ВЧ 60 Гц + полка +4 дБ, как в phone_fix.js) равна громкости прежнего синтеза этого ключа;
  - пик файла не выше −2 дБ;
  - если короткому удару не хватает громкости, ограничитель снимает до 3–6 дБ пика, а остаток добирает множитель громкости (до +6…+8 дБ). Множитель хранится в таблице REC, audio.js применяет его при нарезке (float, без обрезки).
- **Метка выравнивания.** Спрайты и музыка начинаются меткой. По ней audio.js поправляет задержку mp3-декодера. Сейчас декодеры Chrome и ffmpeg дают сдвиг 0 мс, а если какой-то браузер сдвинет, нарезка всё равно попадёт.
- **Числа после сжатия** (`tools/verify.py` → `verify.txt`):
  - 67 из 85 вариантов совпадают с синтезом по громкости K с точностью ±0,1 дБ;
  - 6 вариантов замахов тише на 1 дБ нарочно (см. следующий пункт); ещё 12 тише синтеза, потому что множитель громкости упёрся в потолок: crit на 0,4 и 1,7 дБ, h_light на 1,1 и 1,7 дБ, h_earth на 0,4 и 1,8 дБ, ui_click на 0,8–0,9 дБ, ui_book на 1,0 дБ, d_big на 0,8 дБ, chest на 0,3 дБ, ess на 0,2 дБ;
  - замахи нарочно сделаны на 1 дБ тише синтеза, чтобы удар по врагу был слышнее взмаха;
  - пик файлов −2,07 / −2,15 / −2,00 дБ;
  - края всех кусков — ноль;
  - сходство с исходником до сжатия ≥ 0,98;
  - таблица REC в audio.js совпадает с manifest.json.
- **«Телефон»** (`tools/phone2.py`) — все критерии phone_fix.js выполняются:
  - «Невозможная» громче легендарной на 3,7 / 3,2 / 4,8 дБ;
  - hit_f не тише взмаха (+4,0 / +0,1 дБ), d_flesh не тише взмаха (+5,3 / +4,3 дБ);
  - рана героя −28,3 дБ (норма ≥ −30);
  - варианты одного звука расходятся не больше чем на 1,7 дБ по K и 2,6 дБ на телефоне (h_earth).
- **Щелчки:**
  - детектор находит 0 щелчков во всех звуках, кроме d_bone. В d_bone 1–2 срабатывания: это сами стуки костей, и они точно совпадают с началом стуков;
  - шов петли музыки: в исходнике `_loop.ogg` на стыке конец→начало был скачок 0,10 при обычном шаге 0,006, то есть щелчок. Он убран равномощным перекрёстом 60 мс. В браузерном рендере через loopEnd максимальный шаг в шве 0,054 при обычном p99 0,054, всплеск второй разности ×3,2 (щелчок начинается от ×12).
- **Браузер** (`tools/br2.js`, через замок pw_gate, по одному браузеру; `br_smoke.json`, `br_perf.json`):
  - до касания нет ни контекста, ни запросов. После касания загружаются sfx1 и sfx2, встают 42 ключа, все сыграны, 85 кусков нарезаны точно в клипы;
  - музыка волны: запись вместо синтеза, после возврата продолжает с такта;
  - нет сети для записей — играет синтез, 0 ошибок;
  - без OfflineAudioContext декодирование идёт общим контекстом (48 кГц), всё встаёт;
  - толпа 20 с: голосов ≤ 18, ошибок 0, NaN 0, синтез в главном потоке 0 мс;
  - в «Благодарностях» есть все авторы;
  - ошибок страницы 0.
- **Нагрузка:** толпа 30 врагов, 440×956, `?test=1&snd=1`, время JS на кадр, 3 пары запусков, старая audio.js (9994a5c) против новой. Новая 1,61 мс, старая 1,84 мс, то есть −12,8 %: музыка волны теперь запись, а не секвенсор нот. Разброс между прогонами ±15 %.
- **Память:** музыка боя после декодирования ~19,8 МБ (32 кГц, моно), звуки ~6 МБ (24 кГц). Синтезированные буферы заменённых ключей освобождаются.
- **Для прослушки:** все варианты лежат в `_check/audio2/wav/<ключ>_<n>.wav` (в git не входят).
